# TKFMaaR 1.4

正式版，包含自1.2以来已完成的修复及配置编辑功能；本次直接使用1.4版本号，没有单独发布1.3。

## 运行与配置

- 任务执行或暂停时可以修改普通／高级任务选项、游戏设置和自定义关卡。购买清单、次数及关卡选择等普通选项在下次启动队列生效；故障策略在后续模块入口读取。已保存自定义关卡的图片和体力消耗在对应步骤入口读取，当前步骤和恢复重试保留已加载值。每日定时保存后更新后续触发。
- 恢复前端原生日志显示及滚动，只保留最近100条。删除自定义详细日志列表和重复写盘逻辑。

## 任务修复

- 异常恢复增加服务器异常／跨日提示、魔王月卡；复用启动流程处理王城公布栏及广告。已知恢复均不命中时最多发送三次安卓系统返回键，识别到主页时不发送。
- 修复恢复路由对象解析错误，故障调度异常保留完整诊断；恢复不重置购买、征才和体力消耗额度。
- 商城购买付款后已回到商品列表时继续扫描剩余商品，避免正常购买结束误入异常恢复；每日兑换增加选中页签模板。
- 协会商店补全洪水之石、蜡烛和匕首实图；匕首默认选中，受调教道具组“只购买打折”限制。阿克色记录不再默认选中；其他组提供召唤契约、阿克色、银币和银币打折独立选项，商品组使用横线分隔。
- 炼金在点击前重新识别当前画面，避免旧帧重复点击进入已有生产详情；补空栏固定999个蓝宝石。订单按剩余数量分别计次，保留有界重试，错误详情使用关闭按钮返回。
- 全境征才恢复到主页后重新进入并保留批次账目；点击改为识别框中心，加速确认后不重新发放票券提交机会。
- 自定义体力关卡导航使用图片匹配和识别框中心点击，出征与活动页签支持有界重试。

## 升级与配置继承

- 自动检查更新继续使用RShock/TKFMaaR，下载安装由用户确认。
- 可在新目录解压完整包并使用首次启动迁移向导，同时开启旧助手后自动识别来源；导入包含配置、定时设置及自定义关卡图片，导入前备份。详情见[配置迁移](../tasks/config_migration.md)。
- 商城按稳定商品名称保留旧选择。匕首仅首次迁移补选一次，之后尊重用户取消；已有的阿克色记录选择不强制取消。个人配置、日志及用户截图不包含在发布包中。

## 验证范围

本次不额外执行本地自动测试或游戏任务。发布使用对应提交的GitHub Actions资源检查及完整包构建；CI不能替代实机行为验证。新增恢复分支、运行中编辑和资源消耗流程仍需用户在实际环境中确认。
