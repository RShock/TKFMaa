# 配置每日定时执行

实现入口：`assets/resource/custom/TkfmDailySchedule.cs`。MFAAvalonia 2.16.2 已提供原生整体任务定时器，本模块复用 `TimerModel` 的执行、持久化和同分钟去重能力。

## 设置与触发

1. 首次连接并加载资源扩展后，“开始任务”右侧出现“定时任务”，普通及紧凑布局均提供入口。
2. 点击打开当前配置的设置，勾选“每天定时执行当前配置”，输入每天时间，例如 `09:00`。多个时间每行一个，也可用逗号分隔；统一使用电脑本地时间。
3. 点击保存才生效，直接关闭放弃修改。关闭开关并保存可停用该配置的每日启动时间点，文本仍保留方便恢复。
4. 到点由前端启动对应配置当时勾选的任务及选项；修改任务清单无需重新登记时间。当天未启动前端或电脑休眠错过的时间不补跑。

配置按照稳定实例ID绑定，改名不改变归属。窗口只编辑该实例的每日启动定时器，保留其他配置、按周、按月及停止任务定时器；这些仍可通过原生设置管理。

## 调度与边界

- 启用时切换原生“选用配置”，关闭“全局启动全部配置”和“强制定时启动”，保证对应配置执行且不打断运行中的队列。窗口中说明这些全局设置影响，其他定时器明确选择的目标保留。
- 本配置已在运行时跳过该次触发，不等待补跑。多个不同配置仍遵循前端原生多实例规则，不新增跨配置设备排队器。
- 助手须保持运行，电脑须保持唤醒；设备连接及前置/后置操作沿用该配置。此功能不建立系统任务或电脑唤醒计划。
- 保存只是登记，不立即运行；日程由前端原生配置持久化，重启前端后恢复。扩展按钮首次加载需要连接初始化，不以界面启动或保存日程作为实际触发验证。
- [派遣倒计时续约](daily_dispatch.md)为独立单任务预约，每日定时则启动整个配置；每日配置含派遣时会正常应用派遣选项。
