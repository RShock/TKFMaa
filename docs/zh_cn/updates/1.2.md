# TKFMaaR 1.2

## 更新内容

- Windows首次打开新版时提供旧版配置迁移向导，在主界面读取配置前完成导入。
- 打开旧助手后自动检测目录；唯一来源无需选择，点击“导入并结束旧助手”即可。只有同时打开多个旧助手时才需选择，自动刷新保留有效选择。
- 一起迁移全部 `config/`、根 `appsettings.json` 及自定义关卡的入口图、关卡图和附属图片，保留实例、任务选项和定时设置。
- 导入前暂存并核对文件及截图引用，再精确结束该旧助手、备份新版资料并导入；旧目录保留，替换失败时尝试回滚。
- 提示只自动显示一次，可取消、按Esc或关闭；取消后正常打开新版，不结束旧助手。
- 迁移依赖随完整包提供，无需另装Python或.NET SDK；自动更新继续只检查 `RShock/TKFMaaR`。

## 升级方法

普通Windows电脑下载 `TKFMaaR-win-x86_64-v1.2.zip`，解压到独立的新目录，打开新版后按提示同时打开旧助手。先在旧版保存设置、停止任务，再点击导入。迁移结束后检查设备、任务选项和定时设置。

导入时会结束选定的旧助手，模拟器保持运行。未保存到磁盘的编辑无法保证继承；旧目录及新版的 `backup/config-import-*` 备份均保留。其他系统或取消向导后，按[配置迁移说明](../tasks/config_migration.md)手动复制完整用户资料。

## 验证范围

本版通过GitHub Actions执行资源检查和完整发布包构建。未执行实际旧版配置导入或游戏任务测试，迁移效果仍需用户检查。
