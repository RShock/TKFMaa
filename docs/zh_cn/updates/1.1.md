# TKFMaaR 1.1

## 更新内容

- 奖励领取前筛选未满Max角色，用最左侧最低级药水独立强化两次，每次1瓶，再接回原有六页领奖流程。药水不足或响应无法确认时说明原因并停止补点。
- 炼金按当前画面识别收取、交付和奖励确定按钮；空闲生产栏补蓝宝石，点击MAX并确认999个后才开始生产。
- 通用异常恢复支持广告、公告、活动签到“结束时间”和完整左上返回按钮，恢复后继续识别原任务；共享两次恢复额度并保留资源账目。
- 游戏已运行时直接执行当前任务，后台时只切回前台；冷启动看到无遮挡出征即可继续，不再等待广告必须出现。
- 商城分组为交易所常用道具／材料、协会属性石／调教道具／其他，每组默认仅购买打折商品，可独立关闭折扣限制，保留原有商品勾选。
- 加入协会八目鳗、初级体力药水和紧急录用证等设备截图模板；洪水之石仅预留选项，缺图时不购买。
- 恢复自动检查更新，仅使用 `RShock/TKFMaaR` 的GitHub Release；检查开关可由用户关闭，下载和安装由用户确认。
- 关卡截图窗口和配置编辑器新增“不保存并退出”及Esc退出；取消截图不覆盖原图。实时预览改为每0.5秒尝试刷新，前一帧未完成时跳过，避免积压。

## 从旧版升级

普通Windows电脑下载 `TKFMaaR-win-x86_64-v1.1.zip` 完整包。升级前备份原目录，关闭助手后再解压安装。

旧版曾错误关闭并锁定自动检查，因此这部分用户需要手动安装一次1.1。新版会一次性恢复检查，后续保留用户自己的开关选择；远端发布本身无法修改旧进程里锁定开关的代码。若保留旧配置且首次启动仍使用迁移前设置，重新打开助手后生效。

## 实际覆盖

角色强化及随后每日、协会奖励领取已在编码前通过ADB逐步人工观察：两次各消耗最低级药水1瓶，共418银币。该观察不代表新增代码已通过测试。

本轮未执行本地测试或实际更新测试，未自动运行游戏任务。GitHub发布构建沿用现有工作流；新增强化、恢复及商城分支仍需用户在游戏中检查。
