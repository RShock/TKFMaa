## 文档约定

任务文档是功能行为的唯一说明入口，同时服务于用户、贡献者和 AI。流程图表达页面状态和决策，表格补充选项、识别依据和实现位置。未明确写出的行为不得根据推测实现。

任务文档只描述流程、识别依据、选项和实现约束，不代表所有分支均已完成实机验证。
开发说明、测试脚本及实机调试记录保留在维护者本地，不纳入公开目录。
